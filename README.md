This is a Koog agent prototype using Google's Gemini AI. This specifically uses a paid version of Gemini and the Gemini 2.0 Flash LLM. 

In order to use this agent, you will need an API key that has access to this LLM and set it to the environment variable GOOGLE_API_KEY.

The purpose of this agent is to help a user pick a D&D class based on the party role and combat range they would prefer.
